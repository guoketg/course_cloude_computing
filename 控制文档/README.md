# 控制文档

本目录供课程设计者、任课教师和维护者使用，不随学生课程包发布。学生应以仓库根目录 `README.md`、00—09 课程材料、报告模板、`docs/Windows环境准备.md` 和 `docs/运行包接口说明.md` 为学习与提交依据。

## 内容索引

- [课程总体设计方案](课程总体设计方案.md)：课程目标、课时、评价和教学边界。
- [教师实施与验收指南](教师实施与验收指南.md)：开课准备、教师验收和评分复核。
- [研究说明](research/)：参考项目分析、技术证据和早期实验核验。
- [验证记录](验证记录/)：历史运行记录、全量命令检查和默认模型实测摘要。
- [验证证据](验证证据/)：由脚本脱敏发布的机器可读证据。
- [学生材料发布审计](学生材料发布审计.md)：发布前检查范围与最近一次检查结果。

验证记录中的命令、显示路径和结果用于说明当时实际执行的仓库布局，可能保留迁移前的 `docs/...` 路径。用于打开当前文件的 Markdown 导航链接应指向现有位置；历史事实不因目录整理而改写。

## 写作与发布检查

1. 先确定读者。学生材料只保留学习目标、操作、提交、评分和必要的环境说明；课程维护、教师复测和发布制作内容写在本目录。
2. 学生材料不写编辑指令、维护待办、内部验收身份、维护机绝对路径、证据制作过程或尚待教师完成的操作。
3. 必做要求只能来自学生可见的手册、任务书和评分表。教师指南与验证记录不得暗中增加学生义务。
4. 真实运行结果与制品身份按证据记录，不为了统一措辞改造历史结果。当前状态与历史状态并列时要标明适用版本和边界。
5. 学生入口不导航到本目录。控制文档可以链接学生材料，以便教师检查课程合同。
6. 发布脚本使用白名单收集学生文件，并排除本目录、模型大文件、原始输出和教师答案。根清单与 ZIP 内清单应为同一份 UTF-8、LF 字节内容。
