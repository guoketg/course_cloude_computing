# 学生材料发布审计

本记录用于确认课程仓库与学生发布包的读者边界，不替代实验正确性和模型运行验证。

## 检查范围

- 学生发布白名单中的 Markdown、文本配置、附件说明、模板提示与 CLI 帮助文本。
- 根目录交付清单和 ZIP 条目，确认不包含 `控制文档/`、模型文件、原始 `outputs/` 或教师答案。
- 学生文档的本地链接、PowerShell 围栏和提交/评分合同。
- `控制文档/` 中的导航链接与公开证据位置；历史记录里的旧路径作为历史事实保留。

## 当前整理结果
