# 实验06　实验报告提交及评分标准

## 1. 提交包

文件名为 `实验06_学号_姓名.zip`。报告可为Markdown或PDF，证据使用原始JSON/TXT，不提交环境、模型权重或完整缓存。

```text
实验06_学号_姓名/
├─ 实验报告.md（或PDF）
├─ evidence/
│  ├─ four_cases.json
│  ├─ threshold_sweep_dev.json
│  ├─ evaluation_dev_extractive.json
│  ├─ evaluation_test_extractive.json
│  ├─ evaluation_dev_ollama.json（真实成功时）
│  ├─ frozen_settings.json
│  ├─ manual_faithfulness.md
│  └─ model_status_and_failure.md
├─ changes/（修改前后源码及diff）
└─ AI使用记录.md
```

若个人改动影响了评价，分别保存before/after文件，不能以同名覆盖后失去基线。模型SKIP时保留原因和教师证据来源，不生成虚假ollama结果。

## 2. 报告结构

### 2.1 身份、输入与版本

写明姓名、学号、日期、当前索引模式与版本、问题集SHA256、代码哈希。说明使用的是实验05哪次索引；不能只写“最新版”。

### 2.2 运行前判断

附四类问题的原始预测：有证据、资料外、越权、固定注入。另写阈值提高会如何影响误接受和误拒答。预测必须先于运行，错了可以修正并分析。

### 2.3 指标手算

至少手算一道多来源题的Recall@K和一个分组拒答率，明确分子分母。说明为何不可回答题的Recall为null而不是强行记0。

### 2.4 开发集对照与独立实现

比较0.05、0.13、0.40三种门控阈值，指出至少一道改变判定的题，附分数。若个人数据确实没有变化，应解释其分布并提出改进样本。

说明自己如何修改第二条证据的纳入条件，提交伪代码和diff。比较单来源与多来源题，讨论减少冗余是否损失完整性。

### 2.5 真实模型与人工忠实度

给出实际model_id、digest、输入/输出token、加载/生成/客户端耗时，说明单位。至少人工评审两题，每题逐句或逐条判断“支持、矛盾、无依据、不完整”，引用原文证明。

| qid | 摘录结果 | LLM结果/状态 | 引用存在 | 人工事实支持 | 错误层次 |
|---|---|---|---|---|---|
| 自填 | 原始证据摘要 | 实测或SKIP | 实填 | 原文对照 | 检索/门控/选择/生成/引用 |

LLM真实失败不扣“诚实运行”分；把流畅语言当正确答案、隐藏引用失败或虚构token会影响相关成绩。

### 2.6 冻结与测试

写明何时冻结阈值、K和证据选择，再展示测试结果。测试集被用于调试时明确说明，不再声称未见评估。总结至少一个限制，即使固定测试全为1.0。

### 2.7 故障和AI记录

保存一次Ollama不可达或其他真实失败的完整原因及恢复动作。AI日志记录用途、采纳内容和本人核验。预测、指标手算、核心规则和人工忠实度不得交给AI代做。

## 3. 评分标准（100分）

| 项目 | 分值 | 验收依据 |
|---|---:|---|
| 环境、身份与索引版本 | 5 | 真实输入身份和运行路径 |
| 四类问题与门控理解 | 20 | 可回答/资料外/权限/注入的实际结果，能解释生成前拒答 |
| 分组评价与手算 | 20 | 分子分母正确，开发集对照不偷看测试调参 |
| 独立证据选择改动 | 20 | 先预测、自己实现、diff、单/多来源对照 |
| 真实LLM对照及人工评审 | 15 | 实际模型证据与两题人工核查；环境降级需真实标明教师证据来源 |
| 冻结测试与故障分析 | 10 | 冻结设置、测试逐题、错误层次清楚 |
| 报告、证据与AI记录 | 10 | 不混淆摘录/LLM、引用存在/忠实度，不伪造 |
| 合计 | 100 | 可选更大模型不替代基础任务 |

课程默认模型不是按跑分给学生排名。改进后指标下降但能解释原因、过程真实，可取得分析和独立实现分；删除失败题或修改标准答案不能得到评价分。

## 4. 随机口头验收

解释以下任意三项：门控为何在模型前；全部拒答如何“刷高”指标；Recall与Hit的区别；为什么保留合法引用仍能幻觉；token与人民币为何不能直接等同；自己的证据选择改动是否影响多来源题；CPU加载时间与生成时间如何区分。

## 5. 提交前自查

- [ ] 四类问题和对应原因齐全。
- [ ] 分组指标说明了分母和null含义。
- [ ] 独立修改有前后结果，不是只改变量名。
- [ ] 真模型身份、耗时单位、token来自实际API。
- [ ] 两题人工忠实度检查有原文支持。
- [ ] 测试冻结记录与实际代码一致。
- [ ] 模型失败或SKIP没有伪装成功。
