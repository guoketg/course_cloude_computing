# 实验05　实验报告提交及评分标准

## 1. 提交方式

在个人项目中整理 `提交/实验05_学号_姓名/`，压缩为同名ZIP。提交课程允许的Markdown或PDF报告，不提交 `.venv`、模型缓存、整份依赖目录。所有数值来自自己的真实输出；教师示范证据单独标识。

建议结构：

```text
实验05_学号_姓名/
├─ 实验报告.md（或PDF）
├─ evidence/
│  ├─ baseline_lexical.json
│  ├─ chunking_changed.json
│  ├─ semantic_comparison.json（实跑时）
│  ├─ model_status.md
│  ├─ knowledge.manifest.json
│  ├─ query_comparison.md
│  └─ failure_recovery.txt
├─ changes/
│  ├─ intelligence_before.py
│  ├─ intelligence_changed.py
│  └─ changes.diff（或逐行修改说明）
└─ AI使用记录.md
```

`chunking_changed.json` 是48/12等个人改动运行结果的副本，不能恢复参数后才复制。`semantic_comparison.json` 必须含实际模型身份和运行结果；SKIP时不建立假的结果文件，在model_status写原因与教师证据来源。

## 2. 报告必须包含的部分

### 2.1 实验身份与环境

姓名、学号、日期、Windows/Python版本、项目路径、前四次实验完成情况。附一张连续显示身份与索引结果的截图。截图不能替代JSON证据。

### 2.2 运行前预测

保留以下预测的原稿和时间：16条记录到有效文档数的算式；切分由160/32改为48/12的影响；同一问题在public/internal下的差别；两条自拟查询在词法与语义模式下的差异。

预测错误不直接扣分，缺少先验预测或用运行结果倒填预测会扣分。运行后要明确写出你修正了什么认识。

### 2.3 原理解释与数据路径

用自己的话解释doc_id/version/status/visibility、二元词项、IDF、归一化、BM25与RRF。必须提交独立实现的rrf_student.py，用A/B/C两列表手算并验证融合分，再用D验证缺席贡献为0，并说明分数不是概率。

画出实验04统计快照与政策语料如何进入索引血缘，再指出问答文本与实时统计走不同数据路径。

### 2.4 操作与对照

至少有下表，不得只截完整终端：

| 条件 | 有效文档/片段数 | 首个命中与分数类型 | 版本 | 解释 |
|---|---|---|---|---|
| 词法160/32 | 实填 | 实填 | 实填 | 基线 |
| 个人切分 | 实填 | 实填 | 实填 | 边界/冗余变化 |
| 语义模型 | 实填或SKIP | 实填 | revision | 真实对照与限制 |

另列两条自拟问题的TF-IDF、BM25、hybrid命中来源。语义结果较差同样保留，不能只展示成功的一题。

### 2.5 故障与恢复

保存源文件改变引起StaleIndexError的输出，以及重建后的新版本。解释为何仅加空行也触发变化，为什么不能手改manifest绕过。

### 2.6 独立修改与AI使用记录

列出自己修改的行、修改目的、预期与实际。AI记录至少写“任务、使用工具、输入摘要、采纳内容、本人验证、未采纳原因”；未使用写“未使用”。AI不能替代上述预测与核心改动。

## 3. 评分标准（100分）

| 项目 | 分值 | 得分依据 |
|---|---:|---|
| 身份、环境和前序血缘 | 10 | 当前项目解释器、真实统计哈希、输入完整 |
| 版本/状态/权限理解 | 20 | 有效文档正确，能解释先选最新版再过滤，权限正负例 |
| 词法与融合检索 | 20 | 三类分数解释、RRF独立函数及手算、实际命中与来源 |
| 独立切分与查询对照 | 20 | 先预测、真实代码差异、两条自拟查询、结果解释 |
| 真实语义模型对照与分析 | 15 | ID/revision/维度和真实结果；经确认环境降级则分析教师真实证据并如实标识 |
| 故障恢复与产物完整 | 10 | 实际失败、恢复版本、可复核文件 |
| AI记录与表达准确 | 5 | 不把词法当神经嵌入，不伪造模型运行 |
| 合计 | 100 | 高阶模型调参不占必做评分分母 |

评分不要求语义模型优于词法，也不以下载速度作为技术能力。可选更大模型、重排序器或向量数据库只用于拓展讨论，不替代上述基础证据。

## 4. 验收口头问题

教师随机要求解释2—3项：为什么13个有效文档；撤回v2后能否返回v1；RRF零相关文档为何仍有分数；public过滤放在哪里；更换模型revision为何要重建；自己的切分改动影响了哪个结果。

能够复述命令但不能解释核心代码，相关原理/独立改动项不计满分。报告只写“运行成功”“效果良好”而没有数值与失败分析，不视为完成。
