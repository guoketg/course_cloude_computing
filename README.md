# 云计算与大数据处理：本科实验课程

本课程面向计算机专业、尚无大数据开发经验且编码基础偏弱的本科生。32 个实验学时，8 个实验，每次 4 学时；另设两周个人综合项目。开课前用小测确认 Python 字典、函数、文件读写和基础 SQL，需要时安排短复习，不假设学生已经熟练掌握整套工程工具。

**贯穿应用：校园公共计算资源使用分析与规则查询平台。** 管理员查看使用量与失败，学生查询带来源的公开规则，维护者依据版本、权限和恢复证据决定能否发布。AI 推理日志只是已有数字服务的一类合成工作负载，生成这些课程数据不需要运行模型；校园政策与数据均为课程自制材料，不代表真实学校制度。

先阅读 [课程导论与课前准备](<00. 课程导论与准备/课程导论.md>)，从最终响应、原文来源和发布失败单理解两条主线；再阅读 [课程总体设计方案](课程总体设计方案.md)。导论占实验 01 的前 45—50 分钟，不新增一次实验；依赖与自愿选择的本地模型在课前准备，课堂只做短健康检查。

## Windows 运行基线

沿用 AID 的 Windows、Python 3.12、CPU、约 16GB 内存条件，不要求 GPU 或付费 API。推荐 Windows 11 x64，原生 Python 路线不要求 WSL；Docker 部署对照另见实验 07。首次下载安装由教师课前组织，不能占满第一个实验。建议为环境、模型和个人副本预留至少 8GB 空间，扩容数据另计。

把本目录放到 `C:\BDP`。在 PowerShell 中逐条执行，下列命令只完成环境和原始数据初始化，不替代八份实验手册：

```powershell
Set-Location C:\BDP
$env:PYTHONUTF8 = '1'
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --index-url https://mirrors.tuna.tsinghua.edu.cn/pypi/web/simple -r requirements.lock.txt
.\.venv\Scripts\python.exe -m pip check
.\.venv\Scripts\python.exe -m coursekit identity --student-id 20260001 --lab 01 --stage start
.\.venv\Scripts\python.exe -m coursekit seed --rows 20000
.\.venv\Scripts\python.exe -m coursekit lab01
```

请把学号改成自己的学号。所有后续命令都在本项目根目录执行。直接调用 `.venv` 中的解释器，不必修改系统执行策略或激活环境。初始数据包含 20,000 条合法唯一事件、100 条重复、2 条非法事件；实验 02 应证明 `20,102 = 20,000 + 100 + 2`。

实验 05、06 各有两条完整路径。基础路径使用词法检索和确定式原文摘录；本地模型路径使用固定 BGE 检索编码器和默认 Qwen3.5 0.8B Q8_0 生成模型。两条路径都能完成必达目标并获得满分；模型路径无需付费，但完全由学生自愿选择。不运行模型无需写 `SKIP`，也无需分析教师模型输出。当前大内存 Windows 主机已完成 CPU 默认组合的实验 05/06 实测并保存新证据；真实 16 GB、无 GPU 机器的整机峰值与全流程认证尚未完成。

## 学习与技术边界

学生可以完全不用 AI 助手。使用者可以请 AI 解释库接口、解读错误或审查代码，但要自行核实并简短披露用途；未使用者无需提交空白记录。每章保留一个小数据预测、一个关键局部改动和一个变式验证，评分看证据与理解，不看是否使用 AI 或模型。

Moto 运行真实 HTTP/S3 SDK 请求，但它是内存中的云接口模拟器；Dask 使用本机多个独立 worker 进程，不代表跨机容灾；SQLite 实验实现单数据库内事务微批，不宣称 Kafka 集群或全局 exactly-once；Parquet 文件与清单也不冒充完整 Iceberg 表。把实验机制映射到生产系统是课程中的分析任务。[技术选型依据](docs/research/technology-evidence.md) 说明这些取舍与官方来源。

## 维护与复现

`requirements.lock.txt` 固定本次 Windows 基线完整依赖，`requirements.txt` 列直接依赖；模型依赖单独放入 `requirements-models.lock.txt`。`requirements.container.txt` 用于可选 Linux 容器，并单独验证，不能直接复制包含 Windows 专有依赖的锁文件。升级前要重新检查命令、输出和模型评价，不以“安装成功”代替完整验收。

数据和输出均保存在本机。运行实验会写本课程的数据/结果目录；不同实验对照前按手册复制结果。无需上传个人数据、云密钥或付费调用。`IDENTITY_CODE` 只用于关联学号、实验和截图，不是身份认证或防伪签名。
