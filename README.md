# 云计算与大数据处理：本科实验课程

欢迎来到《云计算与大数据处理》。八次实验共 32 学时，每次 180 分钟，之后还有一个两周个人综合项目。你不需要有大数据项目经验；开始前复习 Python 字典、函数、文件读写，以及 SQL 的 `SELECT`、`WHERE`、`GROUP BY` 和主键即可。

你将逐步完成一个“校园公共计算资源使用分析与规则查询平台”：管理员查看使用量和失败，普通用户查询带来源的公开规则，运维人员根据版本、权限和故障证据决定是否发布。课程中的 AI 推理事件只是数字服务工作负载的一种合成样例；生成日志不需要运行模型，规则和数据也不代表真实学校制度。

先阅读 [课程导论与准备](<00. 课程导论与准备/课程导论.md>)。导论用三个最终响应解释两条数据主线，并在实验 01 的前 45—50 分钟完成。依赖和自愿选择的本地模型应在课前准备好，课堂从短健康检查开始。

## 第一次运行

建议使用 Windows 11 x64、Python 3.12、CPU 和约 16 GB 内存。基础路径不要求 GPU、Docker、云账号或付费 API。选择本地模型路径时，准备约 8 GB 可用磁盘空间，并先关闭占用大量内存的程序；若模型运行过慢或内存不足，可改做手册中同分的词法检索和确定式摘录路径。

把课程目录放到短路径，例如 `C:\BDP`。在 Windows PowerShell 中逐条运行：

```powershell
Set-Location C:\BDP
$env:PYTHONUTF8 = '1'
py -3.12 -m venv .venv
$coursePyPI = 'https://mirrors.tuna.tsinghua.edu.cn/pypi/web/simple'
.\.venv\Scripts\python.exe -m pip install --index-url $coursePyPI -r .\requirements.lock.txt
.\.venv\Scripts\python.exe -m pip check
.\.venv\Scripts\python.exe -m coursekit identity --student-id 20260001 --lab 01 --stage start
.\.venv\Scripts\python.exe -m coursekit seed --rows 20000
.\.venv\Scripts\python.exe -m coursekit lab01
```

把示例学号替换为自己的学号。后续命令都在能看到 `coursekit`、`data` 和 `requirements.lock.txt` 的课程根目录执行，并直接调用 `.venv` 中的解释器。初始事件包含 20,000 条合法唯一记录、100 条重复记录和 2 条非法记录；实验 02 会验证它们的去向。

实验 05、06 各有两条完整路径。基础路径使用一种关键词检索和确定式原文摘录；本地模型路径使用固定 BGE 检索编码器和 Qwen3.5 0.8B Q8_0 生成模型。两条路径完成相同的版本、权限、引用和评价目标，任选一条按对应评分标准提交即可。模型路径免费且自愿；在线付费 API 也完全自愿，课程不指定服务，密钥不得提交。

## 怎样学习和留证

每章都按同一节奏推进：先用小样本预测，运行现成脚手架，查看关键字段，完成一处局部代码改动，再用正例、负例或参数变式验证。结果与预测不一致并不等于实验失败；保留差异、定位原因并重新验证，才形成完整证据。

AI 助手同样是自愿工具。你可以请它解释 API、报错或代码含义，但要自己核对建议并完成手册指定的预测、关键改动和结果解释。实际使用者提交简短记录；未使用者不交记录。评分依据是可复核结果、代码差异和解释能力，不依据是否使用 AI 或模型。

Moto 让你通过真实 HTTP 和 S3 SDK 操作对象，但它不是公有云；Dask 在一台电脑上运行多个进程，不代表跨机容灾；SQLite 事务只保证本实验数据库内的提交边界；Parquet 文件和清单也不是完整湖仓系统。报告应说明你实际验证了什么，并保留原始结果、失败记录和恢复后的复验。

## 环境与数据安全

`requirements.lock.txt` 固定基础依赖版本，`requirements-models.lock.txt` 用于可选模型路径，`requirements.container.txt` 用于实验 07 的可选容器练习。不要临时整体升级依赖，也不要把 `.venv`、模型权重、缓存或密钥加入提交包。

数据和结果都保存在本课程目录。`IDENTITY_CODE` 只把学号、实验和截图对应起来，不是登录凭据或数字签名。实验不需要上传个人数据、真实云密钥或付费调用记录。
