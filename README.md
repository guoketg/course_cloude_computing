# 云计算与大数据处理：AI 时代的本科实验课程

本课程面向已学过 Python、SQL、数据结构、尚未系统学习 Docker 与分布式系统的计算机专业本科生。32 个实验学时，8 个实验，每次 4 学时；按每学时 45 分钟安排为每次 180 分钟。另设两周个人综合项目，独立于这 32 学时。

**贯穿案例：校园 AI 算力与知识服务数据平台。** 从虚构推理任务日志与政策文档出发，依次建立存储接口、可信数据集、分布式统计、增量状态、知识检索、证据问答、HTTP 服务和发布检查。这里的校园政策与数据均为课程自制合成材料，不代表真实学校制度。

先阅读 [课程总体设计方案](课程总体设计方案.md)，了解学习目标、知识递进、时间与考核；正式上机从实验 01 开始。参考 [AID](https://gitee.com/ryukinkou/AID) 与 [MSD](https://gitee.com/ryukinkou/MSD) 的文件编排和证据提交方式，正文与代码为本课程重新编写，参照过程见 [参考仓库分析](docs/research/reference-analysis.md)。

## Windows 运行基线

沿用 AID 的 Windows、Python 3.12、CPU、约 16GB 内存条件，不要求 GPU 或付费 API。推荐 Windows 11 x64，原生 Python 路线不要求 WSL；Docker 部署对照另见实验 07。首次下载安装由教师课前组织，不能占满第一个实验。建议为环境、模型和个人副本预留至少 8GB 空间，扩容数据另计。

把本目录放到 `C:\BDP`。在 PowerShell 中逐条执行，下列命令只完成环境和原始数据初始化，不替代八份实验手册：

```powershell
Set-Location C:\BDP
$env:PYTHONUTF8 = '1'
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.lock.txt
.\.venv\Scripts\python.exe -m pip check
.\.venv\Scripts\python.exe -m coursekit identity --student-id 20260001 --lab 01 --stage start
.\.venv\Scripts\python.exe -m coursekit seed --rows 20000
.\.venv\Scripts\python.exe -m coursekit lab01
```

请把学号改成自己的学号。所有后续命令都在本项目根目录执行。直接调用 `.venv` 中的解释器，不必修改系统执行策略或激活环境。初始数据包含 20,000 条合法唯一事件、100 条重复、2 条非法事件；实验 02 应证明 `20,102 = 20,000 + 100 + 2`。

实验 05、06 采用“先运行可复现基线，再进行真实模型对照”的标准教学路径：BGE 小型中文嵌入模型以 CPU 运行，Qwen3 0.6B 由本地 Ollama 提供生成。教师应课前缓存模型。网络/设备受限的正式降级方案必须如实标记未运行部分，并分析教师实际演示证据；不能把 TF-IDF 当语义嵌入，也不能把摘录当大模型生成。

## 学习与技术边界

AI 可以解释库接口、解读错误、提出排错假设、审查学生已经写好的代码。独立预测、关键公式/核心代码、结果解释、失败归因和现场答辩必须由学生完成；每次都要交一项真实改动及结果差异。具体允许与禁止的环节写在各实验手册中。

Moto 运行真实 HTTP/S3 SDK 请求，但它是内存中的云接口模拟器；Dask 使用本机多个独立 worker 进程，不代表跨机容灾；SQLite 实验实现单数据库内事务微批，不宣称 Kafka 集群或全局 exactly-once；Parquet 文件与清单也不冒充完整 Iceberg 表。把实验机制映射到生产系统是课程中的分析任务。[技术选型依据](docs/research/technology-evidence.md) 说明这些取舍与官方来源。
