# 实验08　实验报告提交及评分标准

## 1. 提交包

提交 `实验08_学号_姓名.zip`。报告应使教师仅依靠提交包就能理解检查依据、失败条件与恢复路线；大文件用路径、哈希和前序提交编号引用，不重复提交环境和模型。

```text
实验08_学号_姓名/
├─ 实验报告.md（或PDF）
├─ 发布说明.md
├─ 恢复手册.md
├─ evidence/
│  ├─ release_checks_baseline.json
│  ├─ release_checks_extended.json
│  ├─ version_failure_recovery.txt
│  ├─ quarantine_comparison.md
│  ├─ lineage_table.md
│  └─ identity_screenshot.png
├─ changes/（新增门禁源码与diff）
└─ AI使用记录.md（仅使用 AI 助手者）
```

baseline为7项检查，extended为加入个人质量血缘检查后的结果。若扩展失败，保留实际失败与原因，不制作假的全通过JSON。

## 2. 报告要求

### 2.1 全链路血缘表

按实验01—07列出当前输入/输出、实际哈希或版本、由哪个下游使用。特别写清楚latest.json指向哪个数据库run、评价和HTTP结果对应哪个索引版本。

### 2.2 运行前预测

保留三项先验判断：切换索引后评价/HTTP证据是否失效；修改Parquet而不重跑04时新增门禁应如何失败；把隔离状态改为approved后检索会怎样。

### 2.3 七项基线检查

逐项解释它读了什么、实际做了什么、什么条件失败、证据是什么。不得只复制检查名，也不能把单机回滚、固定注入样本扩大解释为完整生产保障。

| 检查 | 真实输入/操作 | 通过条件 | 实际结果 | 未覆盖的限制 |
|---|---|---|---|---|
| 自填七项 | 文件/查询/副本 | 可执行条件 | JSON字段 | 明确范围 |

### 2.4 故障与恢复

至少包含源文件变化→旧索引失败→重建成功，以及SQLite副本重复插入/事务回滚的解释。说明临时实验不会改动主语料，原数据库以只读方式访问。

### 2.5 独立新增检查

说明silver_lineage的预期、实现、数据路径与diff；重新计算真实Parquet哈希，与silver manifest、latest source_sha256比较。只有函数名没有真实读写/断言不得分。

### 2.6 隔离状态对照

展示临时副本中quarantined/approved两种状态的命中变化，解释审核字段由可信管理员维护的假设。区分“资料被显示”与“系统执行了指令”。

### 2.7 发布说明与恢复手册

写明当前允许发布的是本机extractive服务；真实模型对照的引用/事实失败应单列，不能被7项绿色结果掩盖。明确无真实认证、小型合成题、单进程缓存和单机数据库等范围。

恢复手册按变化类型写命令序列，例如文档更新后重建索引、重评、重测HTTP、重跑门禁。必须解释为何执行，而非只贴一串命令。

## 3. 评分标准（100分）

| 项目 | 分值 | 验收依据 |
|---|---:|---|
| 前序产物与血缘梳理 | 15 | 完整链路、真实哈希/版本、当前数据库指针 |
| 七项真实检查理解 | 25 | 实际运行和逐项解释，包含正例、负例及限制 |
| 故障注入与恢复分析 | 20 | 先失败后恢复，SQLite副本幂等/回滚解释正确 |
| 关键局部改动 | 20 | 新增 silver 检查的预测、代码 diff、正负结果；隔离状态作观察 |
| 发布说明和恢复手册 | 15 | 范围、版本、限制、恢复步骤可操作 |
| 证据诚实 | 5 | 不固定 PASS、不扩大保证、不伪造模型/云发布；是否使用 AI 不影响得分 |
| 合计 | 100 | 真实云、公钥签名等扩展不占必做评分分母 |

真实失败并准确定位可获得相应分析分。只把release_ready改为true不能得到运行分；缺少个人新增检查不能用更多截图替代。

## 4. 现场验收问题

教师随机选择：解释一个哈希能证明什么；指出负例的正例对照；解释旧索引何时失效；演示新增检查在哪个条件失败；说明为什么真实模型不合格时默认摘录门禁仍能通过；指出生产身份认证与课程role模拟的差别。

## 5. 自查清单

- [ ] 基线7项与扩展8项证据分开保存。
- [ ] 所有检查都有真实输入和可失败条件。
- [ ] 没把sha256写成来源真实的保证。
- [ ] 没把SQLite副本回滚写成分布式exactly-once。
- [ ] 没把固定攻击样本写成通用注入免疫。
- [ ] 没把本机摘录通过写成LLM生产发布成功。
- [ ] 新增检查、隔离对照与恢复路线可复核。
