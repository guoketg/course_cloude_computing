# 默认模型实测记录

本记录覆盖课程默认组合：`BAAI/bge-small-zh-v1.5` 与 `Qwen3.5-0.8B-Q8_0.gguf`。教材主路径先在实验 05 生成并保留 semantic 检索证据，再恢复 lexical 索引；实验 06 的 extractive 与 Qwen dev/test 均使用恢复后的 lexical 证据。实验 07/08 继续验证无大模型参与的 extractive 基础服务。基础实验 01—08 的独立结果另见 `base` profile。未运行任何挑战模型，且所有步骤均在隔离的 `BDP_ROOT` 中执行。

## 模型制品与导入

Qwen GGUF 来自 ModelScope 仓库 `ggml-org/Qwen3.5-0.8B-GGUF` 的固定 revision `f4fd0fca9036bac9116b2abf38797fad94b0087e`。下载链实际观察为 `modelscope.cn` 到 `cdn-lfs-cn-1.modelscope.cn`，文件共 `833592096` 字节，SHA-256 为 `37ae482d336108d23516fa35e8e0c4126688d81018b87178a18d752a1357814f`。该哈希与上游固定 GGUF 相同。

正式执行 `python scripts/prepare_generation.py import-ollama` 后得到本地标签 `bdp-qwen35:0.8b-q8_0`，Ollama digest 为 `de4506c7a2b826cc6f540640208223a770dc62d49513b8ff59d21f6e3364fdea`。随后执行 `verify`，文件哈希与 Ollama digest 均再次通过。

BGE 文件来自 ModelScope `BAAI/bge-small-zh-v1.5` 固定 revision `8399f11f8da998fe932df2684586c92024219d05`。权重与关键 tokenizer/config 文件均经过完整下载和逐文件 SHA-256 比对。课程索引公开记录逻辑模型 ID `BAAI/bge-small-zh-v1.5`，本地目录内容 revision 为 `57f3460a6110a0c86fc263b155d6ca28a86a3c1dd87aacbe78220d4a2e5f7de0`。

## 隔离运行方式

模型阶段使用以下环境约束：

```powershell
$env:BDP_ROOT = (Resolve-Path '.\outputs\smoke-35241a20411644c7ab420f7defe20cbc').Path
$env:BDP_EMBED_MODEL = (Resolve-Path '.\models\bge-small-zh-v1.5').Path
$env:HF_HUB_OFFLINE = '1'
$env:BDP_OLLAMA_MODEL = 'bdp-qwen35:0.8b-q8_0'
```

在此环境中先执行 `lab05 --mode semantic` 保存 BGE 结果，然后执行 `lab05 --mode lexical` 恢复教材主索引。随后在同一个 lexical index version 上执行实验 06 的 extractive 与 Ollama dev/test，再运行仅监听 `127.0.0.1` 的实验 07 基础服务和实验 08 治理门禁。最后使用：

```powershell
python scripts/capture_validation.py --profile default-model `
  --source-root .\outputs\smoke-35241a20411644c7ab420f7defe20cbc `
  --model-root . `
  --target-root .\outputs\new-validation\captured
```

捕获成功，共保存 17 个证据文件。公开捕获目录未发现用户绝对路径或带签名 CDN 查询参数。

## 资源证据边界

Ollama `api/ps` 在模型加载时报告模型大小 `893554523` 字节、VRAM `0`、context `2048` 与 `100% CPU`。这项 loaded size 不是整机 RAM。

三次独立 Qwen 探针期间，按 Windows 进程名 `ollama*` 采样到的 Working Set 合计峰值为 `186724352` 字节。加载后的单次快照只列到 `ollama` 与 `ollama app`，没有观察到独立 runner 进程名，因此该数字只表示被该过滤条件覆盖的部分进程，不能称为模型或整机内存峰值。

验证主机物理内存约 `93.04 GiB`。本轮证明默认参数 `think=false`、`num_gpu=0`、`num_ctx=2048`、`num_thread=2`、`num_predict=256`、`temperature=0` 可以走 CPU 路径，并证明 GGUF 与 Ollama 的运行兼容性；尚未在物理 16 GiB 主机上认证内存上限。
